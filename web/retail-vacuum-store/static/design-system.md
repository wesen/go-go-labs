# VacuumMart Design System

## Overview
Comprehensive design system for a vacuum cleaner retail store focusing on conversion optimization and seamless user experience.

## Brand Identity
- **Primary Color**: #1f2937 (Dark Gray)
- **Secondary Color**: #3b82f6 (Blue)
- **Accent Color**: #10b981 (Green) 
- **Error Color**: #ef4444 (Red)
- **Warning Color**: #f59e0b (Amber)

## Typography
- **Headings**: Inter, sans-serif (700, 600, 500)
- **Body Text**: Inter, sans-serif (400, 300)
- **Code/Technical**: JetBrains Mono, monospace

## Customer Journey Flow

### 1. Browse Phase
- **Entry Points**: Homepage hero, category navigation, search
- **Goal**: Product discovery and category exploration
- **Key Features**: 
  - Product grid with filters
  - Quick view overlays
  - Comparison tools
  - Featured product carousels

### 2. Product Details Phase  
- **Entry**: Product card clicks, search results
- **Goal**: Detailed evaluation and decision making
- **Key Features**:
  - Image galleries with 360° views
  - Specification tables
  - Customer reviews and ratings
  - Related/recommended products
  - Add to cart prominence

### 3. Cart Phase
- **Entry**: Add to cart actions, cart icon clicks
- **Goal**: Cart review and quantity adjustments
- **Key Features**:
  - Mini cart dropdown
  - Full cart page with item management
  - Shipping calculator
  - Promotional code input
  - Continue shopping options

### 4. Checkout Phase
- **Entry**: Proceed to checkout button
- **Goal**: Order completion with minimal friction
- **Key Features**:
  - Single-page checkout flow
  - Guest checkout option
  - Multiple payment methods
  - Order summary sidebar
  - Progress indicators
